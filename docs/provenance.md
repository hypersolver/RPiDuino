# 來源與授權

板卡定義、建置及上傳工具、範例和歷史板卡包源自 [Raspberry Pi XDOS](https://github.com/hypersolver/raspberry-pi-xdos)。原專案的自研檔案尚未另外指定統一授權。上游元件保留各自的授權與署名。

- 裸機建置使用固定版本的 [Circle 51.1.1](https://github.com/rsta2/circle/tree/7a81e1b480fe7d19fc1fc695b89bff0a0848f44b)。[GPLv3 全文](../licenses/Circle-GPL-3.0.txt)
- XDOS XAPP 標頭包含帶有原始通知的 FatFs 檔案及 LVGL 9.4 標頭。[LVGL 授權](../licenses/LVGL-LICENSE.txt)
- XDOS 主系統保留其上游 [XD OS MIT 授權](../licenses/XDOS-MIT.txt)。[原專案的來源清冊](https://github.com/hypersolver/raspberry-pi-xdos/blob/main/SOURCE_MANIFEST.md)
